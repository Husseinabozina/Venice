# VENICE ERP — نموذج تفاعلي

نموذج تفاعلي لنظام إدارة مصنع **VENICE FURNITURE WORKSHOP W.L.L** (البحرين): مطابخ وأثاث وديكورات.
النموذج بيوري شكل النظام وطريقة التعامل معاه، وكل الأقسام مربوطة ببعض ببيانات تجريبية.

**رابط التجربة (بعد تفعيل GitHub Pages):** https://husseinabozina.github.io/Venice/

---

## أهم حاجة فيه: جولة الدورة الكاملة

من شاشة الدخول اضغط **«ابدأ جولة الدورة الكاملة»**، وهتمشي بنفسك في رحلة مطبخ كامل في ١٤ خطوة:

1. عميل جديد (منى حسين)
2. عرض سعر من ملف العميل
3. العميل وافق: تحويل العرض لفاتورة + مشروع بضغطة واحدة
4. تسجيل المقدم وإصدار سند قبض
5. اعتماد التصميم
6. صرف خامات على المطبخ (التكلفة تتحدث لوحدها)
7. تنبيه إن الخشب قرّب يخلص، وأمر شراء للمورد
8. استلام البضاعة (المخزن يزيد)
9. الورشة على لوحة كانبان
10. ربح المطبخ محسوب من الصرف الفعلي
11. الدفعة التانية قبل التركيب
12. التسليم
13. لوحة التحكم بتتحدث بكل اللي حصل

في كل خطوة الزرار المطلوب بيتنوّر بالدهبي، والفورمات فيها زرار **«املأ ببيانات تجريبية»**، فمش محتاج تكتب حاجة.

## الدخول

مافيش تسجيل حقيقي. اختار دور وادخل على طول، وتقدر تبدّل الدور من القايمة الجانبية:

| الدور | بيشوف |
| --- | --- |
| المدير العام | كل الأقسام |
| المبيعات | العملاء، كشف الحساب، العروض والفواتير، المشاريع |
| المحاسب | العملاء، كشف الحساب، العروض والفواتير، المشتريات، التكلفة، التقارير |
| مدير الإنتاج | المشاريع، الإنتاج، المخازن، التكلفة |
| أمين المخزن | المخازن، المشتريات |
| الموارد البشرية | الموظفين |
| الفني | مهامه في الورشة بس |

## الشاشات

- **لوحة التحكم:** أرقام مختلفة لكل دور، وقايمة «محتاج متابعة النهارده» (مشاريع متأخرة، دفعات قرّبت، خامات تحت الحد)، وسجل آخر التحركات
- **العملاء:** بحث بالاسم أو التليفون، وملف لكل عميل فيه أزرار بالأرقام (مشاريع، عروض، فواتير، المتبقي)، وخريطة وواتساب، و**العملاء التابعين** لشركة (زي شركة مقاولات تحتها أصحاب فلل)
- **كشف حساب العميل:** مدين ودائن ورصيد بعد كل حركة، وكشف مجمّع للشركة وعملائها التابعين، وطباعة PDF
- **العروض والفواتير والسندات:** عرض سعر ببنود، وشريط يوضح العرض وصل لفين، وتحويل لفاتورة بدفعتين، وتسجيل دفعات، وعرض/فاتورة/سند بهوية الشركة الأسود والدهبي، وإرسال على الواتساب
- **المشاريع:** ملف لكل مشروع بالمراحل الـ٨ وتواريخها، والرسومات والمرفقات، والخامات اللي اتصرفت، والربحية لحد دلوقتي
- **الإنتاج:** لوحة كانبان بالسحب والإفلات، والكارت الأحمر متأخر
- **المخازن:** الرصيد وحد الطلب وقيمة المخزون، وصرف خامات على مشروع، وسجل الحركات
- **المشتريات والموردين:** أوامر شراء، واستلام بيزوّد المخزن، ومستحقات كل مورد
- **تكلفة المشاريع:** خامات + عمالة + ماكينات + مصاريف = التكلفة، والربح والهامش لكل مشروع
- **الموظفين:** حضور النهارده بضغطة، والرواتب حسب القسم
- **التقارير:** ٧ تقارير بتتصدّر Excel (CSV) وتتطبع PDF
- **الإعدادات:** بيانات الشركة، وأسعار الساعة، ومصفوفة الصلاحيات، وبنود العقد، وسجل التعديلات

وفي كل مكان: بحث واحد من أي صفحة (`Ctrl K`)، ورسائل تأكيد، وتأكيد قبل الخطوات المهمة، وشكل مظبوط على الموبايل.

## التشغيل على جهازك

النموذج HTML وجافاسكريبت من غير أي مكتبات، فمش محتاج `npm install`. بس لازم يتفتح من سيرفر صغير (مش بالضغط المزدوج على الملف):

```bash
python3 -m http.server 8000
# وبعدين افتح http://localhost:8000
```

## تفعيل الرابط على GitHub Pages

من صفحة المشروع على جيت هاب: **Settings ← Pages ← Build and deployment**، اختار **Deploy from a branch**، والفرع `main` والفولدر `/ (root)`، واضغط **Save**. بعد دقيقة أو اتنين الرابط هيشتغل.

## البيانات

البيانات محفوظة في متصفح كل واحد (localStorage). أي حد يفتح الرابط بيبدأ من البيانات التجريبية، وتقدر ترجّعها لأولها من **الإعدادات ← إعادة البيانات**. وبدء الجولة بيرجّع البيانات لأولها تلقائيًا.

## من النموذج للنظام الحقيقي

| في النموذج | في النظام الحقيقي |
| --- | --- |
| `js/data.js` (البيانات في المتصفح) | قاعدة بيانات PostgreSQL + Prisma |
| كل دالة في `act` (زي `convertQuote`) | عنوان REST API على Node.js (زي `POST /api/quotes/:id/convert`) |
| اختيار الدور من شاشة الدخول | تسجيل دخول بالإيميل وJWT، والصلاحية بتتأكد على السيرفر |
| الطباعة من المتصفح | PDF بيتولّد على السيرفر |
| المرفقات (أسماء بس) | تخزين سحابي (DigitalOcean Spaces) |
| الشاشات (HTML/JS) | Next.js + React بنفس التصميم |
