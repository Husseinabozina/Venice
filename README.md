# VENICE ERP — نموذج تفاعلي

نموذج تفاعلي لنظام إدارة مصنع **VENICE FURNITURE WORKSHOP W.L.L** (مملكة البحرين).

**رابط التجربة:** https://husseinabozina.github.io/Venice/

## الأقسام

لوحة التحكم، والعملاء، وكشف حساب العملاء، وعروض الأسعار والفواتير، والمشاريع، والإنتاج، والمخازن، والمشتريات والموردون، وتكلفة المشاريع، والموظفون، والتقارير، والإعدادات.

## الدخول

من شاشة الدخول اختر الحساب (المدير العام، أو المبيعات، أو المحاسب، أو مدير الإنتاج، أو أمين المخزن، أو الموارد البشرية، أو الفني)، ثم «تسجيل الدخول». كل دور يرى الأقسام المسموح له بها فقط، ويمكن تغيير الدور من أسفل القائمة الجانبية.

## الجولة الإرشادية

«جولة الدورة الكاملة» من شاشة الدخول أو لوحة التحكم: 14 خطوة من عميل جديد حتى التسليم والتحصيل.

## الإعدادات الداخلية

في `js/data.js`:

```js
export const DEMO = {
  locked: [...],      // الأقسام المقفلة في القائمة
  rolePicker: false,  // اختيار الدور من شاشة الدخول
  tour: false,        // الجولة الإرشادية
};
```

إضافة اسم قسم إلى `locked` تُظهره في القائمة بعلامة «قريبًا»، وتفعيل `rolePicker` و`tour` يعيد اختيار الأدوار والجولة الإرشادية.

## التشغيل المحلي

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
